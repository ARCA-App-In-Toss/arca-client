# 문서 라우팅

관할·충돌·자율 변경 범위는 `.claude/spec/00_INDEX.md`가 원본이다. 하네스는 그 계약을 복제하지 않는다.

- 시작 위치가 불분명할 때만 00 §1을 읽는다. 충돌은 §4~5, 변경 승인 판단은 §7.1, 구현 착수는 §9를 확인한다.
- 화면: 03의 해당 F → 04 §6의 같은 F → 필요한 IX·CPY·OP만 따른다.
- API: 05의 현재 계약 원본 → BACKEND_API_MIGRATION_GUIDE의 해당 endpoint·오류·응답 유실 처리. 연결 공백은 프로젝트 루트 API_INTEGRATION_GAPS.md를 확인한다.
- 테스트: 08 §3의 해당 family 행 → 07의 해당 MS와 fixture 계약. 모든 family를 한꺼번에 읽지 않는다.
- 토큰/CMP는 02, 경험 방향은 01, 상태/경계는 06의 담당 절에서 찾는다. docs는 제품 정책 확인·충돌 해결에, DECISIONS는 결정 이유 확인에만 연다.

먼저 지정 파일에서 제목/ID를 검색하고 그 절의 끝까지 필요한 내용을 읽는다. `.claude/`는 숨김 경로이므로 명시적 파일 경로 또는 한정된 `rg ... .claude/spec/<담당 파일>`을 쓴다. 저장소 전체를 무차별 검색하지 않는다. 줄 번호는 힌트이며 연결된 문서를 모두 읽으라는 뜻이 아니다.

넓은 phase 범위·`MS-*-*`는 **단계의 커버리지 지도**다. 현재 작업 ID를 먼저 고르고 필요한 선행 불변식만 확장한다. 검색 결과가 없으면 지정 파일의 제목 지도를 한 번 확인한다. 그래도 없으면 누락 경로·ID를 요청하고 추측 계약/반복 검색을 만들지 않는다. 이미 읽은 절은 파일 변경·충돌·컨텍스트 유실 때만 다시 읽는다.
